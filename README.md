# n8n-nodes-jobpostingsapi (Official JobPostingsAPI.com n8n Community & AI Agent Node)

Automate **B2B Outbound Sales Hiring Signals, ATS Job Monitoring (Workday, Greenhouse, Lever, Ashby), and Tech Stack Intent Lead Generation** directly inside **n8n** (`usableAsTool: true` for n8n AI Agents!) via **[JobPostingsAPI.com](https://jobpostingsapi.com)**.

## Installation in n8n
1. Open your n8n instance $\rightarrow$ **Settings** $\rightarrow$ **Community Nodes** $\rightarrow$ **Install**.
2. Enter **`n8n-nodes-jobpostingsapi`** and click **Install**.
3. Get your instant API key (**100 free requests included**, no credit card required) at **[https://jobpostingsapi.com](https://jobpostingsapi.com)**.
